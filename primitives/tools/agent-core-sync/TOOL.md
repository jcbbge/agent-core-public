# agent-core-sync

`agent-core-sync` is installed on PATH from `scripts/`. `--check` reports owned legacy files without writing. It removes only harness entrypoints generated by agent-core-sync, links into this repo's retired rule, command and skill directories, and Codex command copies marked as owned by agent-core. It never creates a harness instruction file and does not touch foreign settings, other hooks or unowned files.

Run on hive and M5 after publishing changes; the repo's post-merge hook also invokes it. No work process or skill bundle is installed by default.
