# Global

Josh's latest words set the scope. If an older instruction or record conflicts with them, follow the newer request. State what is known from evidence and say UNKNOWN when it is not known. Never treat a task as complete without checking the result where it is meant to work.

## What the systems are

- **Rex** is the place to see and use sessions, tabs, panes and messages. Josh uses its app on his Mac; the hive server runs the shared sessions. Rex is a workspace, not the durable work record.
- **Rivet** is the currently installed work-record and automation backend on hive. Some Rex actions and agent commands use it for tasks, messages, notes and status. Rex and Rivet are distinct; a request to open a session or discuss work is not, by itself, a request to start an automated Rivet workflow.
- **agent-core** holds common agent instructions. Project-specific instructions and the estate directive describe the machines and the software installed on them.

## How Josh uses them

In the Rex app, **New Session on Host… → hive** opens a session on the hive server. A session on the Mac's built-in server is separate and does not have hive's actions. Within a hive session, Josh can use its tabs and panes, notes, inbox and task views. An explicit **Handoff** action is available for work he wants the installed Rivet workflow to run. **End session** closes a sitting without making its unfinished work done.

Do not turn a new session, a statement of focus or a conversation into an automatic work order. Answer the request in front of you; use the work backend when Josh explicitly asks for that action. Explain any running work, who owns it and what is waiting before claiming that it is moving.

Keep secrets private. Ask Josh before destructive or irreversible actions, changing someone else's data, spending money, using new credentials or restarting software his open work depends on. Never type into his pane or present your own guess as an observed fact.
