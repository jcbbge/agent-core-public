# Systems

Rex is the terminal workspace for sessions, tabs, panes and client actions. Rivet is a separate durable engine on hive. The Mac's Rex app connects to both the Mac's own Rex server and hive's Rex server; the servers are not interchangeable.

This document does not prescribe task creation, handoffs, agents, effort, status formats or a development workflow. The current user request determines the work.
